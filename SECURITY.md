# Seguridad

Si encuentras una vulnerabilidad, no abras un issue público. Repórtala en privado desde la pestaña **Security > Report a vulnerability** de este repositorio (GitHub Private Vulnerability Reporting).

Incluye pasos para reproducirla y el impacto que ves. Respondemos lo antes posible y te avisamos cuando haya un arreglo.

Solo se da soporte a la última versión de `main`.

## English

Please report vulnerabilities privately via **Security > Report a vulnerability** on this repository. Do not open public issues for security problems.
